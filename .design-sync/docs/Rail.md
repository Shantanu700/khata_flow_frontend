# Rail

The left column of round icon buttons from the HubSpot reference: Dashboard, Khata, Stock, Staff and Bolo, with the current page in white.

## When to use
The app shell's left edge on screens 1024px and wider. Below that it hides; the header carries navigation.

## What you provide
Nothing yet: it renders the five KhaataFlow sections with Dashboard current. Each button has an `aria-label`.

## Rules
- Current item: white circle, black icon. Others: `raised` circle, `ink-muted` icon that turns `ink` on hover.
- 44px circles, 12px apart. It starts 160px down so it lines up with the content below the header and hero.
